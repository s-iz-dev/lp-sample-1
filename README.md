# lp-sample-1（Web制作サービスの見本LP）

## 公開URL
https://s-iz-dev.github.io/lp-sample-1/

## 概要
Web制作サービスの見本LPです．静的HTMLで作成し，スマホ表示に対応しています．

## できること
- LPのコーディング（レスポンシブ対応）
- 既存ページの軽微修正，表示崩れ修正
- 簡単なJavaScript追加（アコーディオン等）

## 対応外
- ログイン機能，決済，個人情報DB，大量スクレイピング

## 使用技術
- HTML
- CSS
- JavaScript（必要最低限）
- GitHub Pages
